# Trap Runner

Мультиплеерный Deathrun для Roblox: один игрок — **Трапер** — бежит по параллельному коридору
за стеклом и включает ловушки, остальные — **Раннеры** — проходят полосу препятствий.
Трасса собирается заново каждый раунд. Весь текст в игре — на русском (шрифт SourceSans, с кириллицей).
Трапер бегает в 3 раза быстрее раннеров (48 против 16) по коридору шириной 20 studs.

**Статус: Фаза 5 — монетизация, прогресс-бар, панель трапера, звуки, VIP. Все фазы готовы.** Трасса из 24–32 сегментов:
ловушки чередуются со связками, сложность растёт к финишу, чекпоинты каждые 6 сегментов, 4 темы.

## Проверка на ПК (Windows)

### Способ 1: готовый файл места, ничего не устанавливая

1. Возьми `TrapRunner.rbxlx` (или собери сам: `rojo build default.project.json -o TrapRunner.rbxlx`).
2. Открой его в Roblox Studio: двойной клик по файлу или **File → Open from File**.
   В режиме редактирования мир пустой — лобби и трасса строятся скриптами при запуске.
3. Вкладка **Test** → блок **Clients and Servers**: выбери **Local Server**, **3 Players** → **Start**.
   Откроются 4 окна: сервер и 3 клиента. На слабом ПК хватит 2 игроков (минимум для раунда).
4. В каждом окне клиента дойди до круга: синий — RUNNER, красный — TRAPPER.
5. В окне сервера открой **View → Output**: там `[Main] Trap Runner server started`,
   `[Track] seed = …`, `[Round] Over: …`. Ошибки показываются красным.
6. Закончить тест: кнопка **Cleanup** (Stop) в окне сервера.

Этот способ годится, чтобы посмотреть игру. Изменения, сделанные в Studio, в репозиторий не попадут.

### Способ 2: живая синхронизация через Rojo (для разработки)

1. Установи Rojo: `winget install Rojo.Rojo` или архив со страницы
   [Rojo Releases](https://github.com/rojo-rbx/rojo/releases).
   Можно через [Rokit](https://github.com/rojo-rbx/rokit): `winget install Rojo.Rokit`, затем в папке проекта
   `rokit install` (поставит Rojo, StyLua и Selene из `rokit.toml`).
2. Скачай проект: `git clone -b claude/roblox-game-y43pbn https://github.com/spremakrolik-png/Roblox`
   или **Code → Download ZIP** на странице ветки.
3. В папке проекта один раз выполни `rojo plugin install` (ставит плагин Rojo в Studio), потом `rojo serve`.
4. В Studio создай место из шаблона **Baseplate**, на вкладке **Plugins** нажми **Rojo → Connect**.
   Скрипты появятся в Studio и будут обновляться при каждом сохранении файла.
5. Проверь, что у `Workspace` включён **StreamingEnabled** (Rojo выставляет его сам; если нет — поставь вручную).
6. Запусти тест, как в шаге 3 первого способа.

Лимит 12 игроков задаётся в Game Settings → Places → Max Players (после публикации).

## Как проверить Фазу 1

В тесте с 3 клиентами:

| Сценарий | Что должно произойти |
|---|---|
| Двое встали в синий круг РАННЕР, один в красный ТРАПЕР | 10 c «Следующий раунд через…», потом 15 c отсчёта: у каждого в HUD своя роль, далеко по оси X строится трасса |
| Конец отсчёта | Раннеры на стартовой площадке, Трапер в коридоре за стеклом; 3 c все заморожены, ворота исчезают, баннеры «БЕГИ!» / «ТЫ ТРАПЕР — останови их всех!» |
| Раннеры добегают до финиша | В kill feed «Name финиширует: 1 место (0:42.3)», места 1-2-3 по порядку пересечения финиша |
| Раннер прыгает в пропасть | «Name падает в пропасть», он появляется в лобби, раунд идёт дальше |
| Все раннеры погибли | «ПОБЕДА ТРАПЕРА!» на экране итогов |
| Раннер стоит на месте 60 c (не доходит до нового сегмента) | «Name выбывает (AFK)», его переносит в лобби, раунд не зависает |
| Трапер закрыл окно клиента посреди раунда | Раунд сразу заканчивается, оставшиеся раннеры отмечены «в живых», победа Раннеров |
| В кругах меньше 2 игроков | На табло и в HUD: «Встань в круг, чтобы играть» |
| Игрок стоит вне кругов при старте отсчёта | Он не участвует и остаётся в лобби зрителем |

Правила выбора Трапера: случайный из круга TRAPPER; если там пусто — случайный из всех участников;
тот же игрок не становится Трапером два раунда подряд, если есть другие кандидаты (кроме случая, когда в круге
TRAPPER стоит только он сам).

Каждая трасса пишет в Output свой seed, тему и список сегментов:
`[Track] seed = 123456, theme = Ледяная пещера, 27 segments: JumpPlatforms1, UpDownHops1, ...`.
Чтобы воспроизвести трассу, впиши этот seed в `GameConfig.Track.DebugSeed` (0 — снова случайные трассы).
Технический лимит раунда (12 минут) закрывает раунд без наград и пишет предупреждение с seed.

## Как проверить Фазу 2

| Что проверить | Что должно быть |
|---|---|
| Несколько раундов подряд | Каждый раз другие сегменты, длина 24–32, одна из 4 тем (название — в HUD во время отсчёта) |
| Сложность | В начале широкие платформы и ступени, к финишу узкие балки, мелкие камни и тонкие столбы |
| Чекпоинты | Неоновые арки «ЧЕКПОИНТ n/N» каждые 6 сегментов; в HUD «Чекпоинт 2/4» |
| Коридор Трапера | Идёт за стеклом вдоль всей трассы от старта до финиша, без прыжков |
| Проходимость | Любой сегмент проходится обычными прыжками (проверено симуляцией: 24 варианта × 300 сидов) |
| Античит | Если раннер пробежал между чекпоинтами быстрее физически возможного (телепорт, спидхак), на финише он «Name: дисквалификация», в Output — `[AntiCheat] ...` |

## Как проверить Фазу 3

Чтобы прогнать все пять ловушек подряд, впиши в `GameConfig.Track.DebugSegments`
`{ "LavaFloor1", "VanishingBlocks2", "ClosingZone2", "CrushingWalls1", "Pistons2" }` (пустой список — обычная
случайная трасса). Тест: 2–3 игрока, один встаёт в красный круг.

| Ловушка | Как сработает (после 0.6–0.8 c мигания и надписи «!! Название ловушки !!» у раннеров в зоне) | Как выжить |
|---|---|---|
| Лавовый пол (LavaFloor) | Пол становится лавой на 3 c | Запрыгнуть на жёлтый блок или выбежать из сегмента |
| Исчезающие блоки (VanishingBlocks) | Ряды плит исчезают волной от начала к концу, через 3 c возвращаются | Успеть добежать до конца |
| Закрывающаяся зона (ClosingZone) | Ворота закрываются, комната заполняется ядом за 2 c | Не быть внутри, когда ворота закрылись |
| Давящие стены (CrushingWalls) | Стены съезжаются к центру | Выбежать вперёд или назад за ~1 c |
| Поршни (Pistons) | Поршни бьют поперёк дорожки и сталкивают в пропасть | Стоять в промежутке между поршнями |

- **Кнопки**: у начала каждого сегмента-ловушки, у дальней стены коридора. Нажать E (или тапнуть) можно
  только Траперу, только рядом и только один раз — потом кнопка серая «ИСПОЛЬЗОВАНО». Раннеры до кнопок не дотягиваются.
- **Kill feed**: «Давящие стены раздавили Name»; падение после удара ловушкой тоже засчитывается Траперу
  («Поршни столкнули в пропасть Name»). Число убийств Трапера — на экране итогов.
- **Зритель**: погибший Раннер сразу смотрит на живых; стрелки `<` `>` (или Q/E) переключают между живыми
  Раннерами и Трапером, `X` — выйти. Финишировавшие и игроки в лобби могут нажать СМОТРЕТЬ.

## Как проверить Фазу 4

**Очки** (начисляются в конце раунда, видны в итогах и в таблице игроков «Очки»):

| Событие | Очки |
|---|---|
| Раннер — 1 / 2 / 3 место | 10 / 5 / 3 |
| Раннер — финиш дальше 3-го места | 1 |
| Трапер — за каждое убийство ловушкой | 1 |
| Трапер — победа (все раннеры погибли) | 5 |

В Studio игрок сразу получает 2000 очков (`GameConfig.Debug.StudioStartPoints`), чтобы проверить магазин, —
в опубликованной игре этого нет. Сохранение: ProfileStore с блокировкой сессии. Чтобы данные сохранялись между
запусками в Studio, включи Game Settings → Security → **Enable Studio Access to API Services** (игра должна быть
опубликована); без этого ProfileStore работает во временном хранилище, и после теста всё сбрасывается.

**Магазин и наборы** (кнопки слева в лобби): «МАГАЗИН» — купить способность за очки; «НАБОР» — выбрать, какие
купленные способности стоят в 2 слотах Раннера и в 2 слотах Трапера. В раунде способности — справа, клавиши 1/2/3
или нажатие на кнопку.

**Способности в лобби.** Вне раунда (в лобби, после выбывания, зрителем) справа показываются способности из обоих
наборов, которые работают без трассы: плавное падение, ускорение, двойной прыжок, рывок, спринт и замедляющая
пушка (в лобби она замедляет других игроков в лобби). Клавиши 1–6. Работают только внутри лобби; щит,
вспышка, дистанционный запуск и перезарядка ловушки — только в раунде. Перезарядки в лобби отдельные от раунда.

| Раннер | Что делает | Перезарядка | Цена |
|---|---|---|---|
| Плавное падение | падение не быстрее 8 studs/с, 3 с | 20 с | 100 |
| Ускорение | +60% скорости на 2,5 с | 15 с | 150 |
| Двойной прыжок | второй прыжок в воздухе (всегда) | — | 250 |
| Рывок | рывок вперёд на 18 studs | 12 с | 300 |
| Щит | спасает от одного удара ловушки (не от падения) | 1 раз за раунд, сам | 500 |

| Трапер | Что делает | Перезарядка | Цена |
|---|---|---|---|
| Спринт | +40% скорости на 4 с | 18 с | 100 |
| Ослепляющая вспышка | белый туман на сегменте напротив, у раннеров в нём — вспышка на экране 3 с | 20 с | 250 |
| Дистанционный запуск | запускает ближайшую готовую ловушку в радиусе 60 studs | 1 раз за раунд | 400 |
| Перезарядка ловушки | возвращает последнюю использованную ловушку | 1 раз за раунд | 450 |
| Замедляющая пушка | 3 выстрела туда, куда смотрит камера; сквозь стекло; попавший раннер замедлен на 60% на 3 с | 8 с | 500 |

**Новые ловушки** (для проверки впиши в `DebugSegments`, например
`{ "FallingCeiling2", "SpinningBlade2", "ArrowVolley3", "IceFloor1", "FakeFloor2", "RisingFlood2" }`):

| Ловушка | Как сработает | Как выжить |
|---|---|---|
| Падающий потолок | панели потолка падают на пол | встать под панель над зелёной нишей |
| Вращающееся лезвие | лезвие на уровне ног крутится 6 с | перепрыгивать, когда проходит мимо |
| Залп стрел | 3 залпа из стены по красным полосам, полосы чередуются | стоять между полосами |
| Ледяной пол | пол на 6 с становится льдом и сносит к краю | идти против течения или уйти с сегмента |
| Ложный пол | случайные плитки мигают и проваливаются на 4 с (в каждом ряду одна остаётся) | уйти с мигающих плиток |
| Кислотный потоп | кислота поднимается до 5 studs | забраться на возвышение (через ступеньку) |

## Как проверить Фазу 5

| Что проверить | Что должно быть |
|---|---|
| Прогресс-бар | Во время раунда вверху полоса с точками: синие — раннеры, золотые — финишировали, серые — выбыли, красная (под полосой) — Трапер, твоя точка крупнее с белой обводкой; белые риски — чекпоинты |
| Панель Трапера | Слева «Ловушки впереди»: 5 ближайших ловушек, через сколько сегментов, «готова / работает / использована» |
| Отставание Трапера | Если живой лидер раннеров впереди на 2+ сегмента — мигает «Лидер раннеров впереди на N сегм. — догоняй!» |
| Звуки | Тиканье на 3-2-1 у ворот и сигнал старта; сигнал у раннера в зоне ловушки; хлопок при смерти; звук способности, нажатий в магазине, финиша, победы/поражения |
| Итоги | Сверху «Твоя награда: +N очков» (с пометкой x2 при пассе), свои строки помечены «(ты)» |
| Способности в лобби | В лобби справа кнопки способностей; рывок и ускорение работают, пушка замедляет другого игрока в лобби |
| AFK | Раннер выбывает только после 60 с без продвижения на новый сегмент |

### Монетизация: что настроить после публикации

1. Опубликуй игру (File → Publish to Roblox).
2. На [Creator Dashboard](https://create.roblox.com/dashboard/creations) → твоя игра → **Monetization**:
   - **Passes**: создай 3 пасса — «x2 Очки», «Доп. слот», «VIP» — и поставь им цену.
   - **Developer Products**: создай 3 пакета очков (500 / 1500 / 5000) и по продукту на каждую способность (10 шт.).
3. Скопируй ID в `src/shared/Config/Monetization.luau`: `assetId` у пассов, `productId` у пакетов и способностей.
   Поле `robux` — только надпись на кнопке, реальную цену задаёт Dashboard: держи их одинаковыми.
4. Пока ID = 0, кнопка не показывается и ничего не продаётся — игра работает и без монетизации.

| Пасс | Что даёт |
|---|---|
| x2 Очки | Очки за раунды ×2 (пакеты очков не удваиваются) |
| Доп. слот | Третий слот в наборах Раннера и Трапера |
| VIP | Золотой «[VIP] Ник» над головой и в чате, золотой салют на финише (очки не меняет) |

Покупки за Robux обрабатывает `MarketplaceService.ProcessReceipt`: ID покупки сохраняется в данных игрока вместе с
наградой, и покупка подтверждается только после сохранения — повторно не выдаётся и не теряется при сбое
сервера. Если способность уже куплена за очки, пока было открыто окно оплаты, игрок получает её цену в очках.
Проверить в Studio: покупки там тестовые (Robux не списываются), но для пассов и продуктов нужны настоящие ID.

## Визуал, музыка и второй шанс

| Что проверить | Что должно быть |
|---|---|
| Замедляющая пушка | У того, у кого она в наборе, на правом плече пушка. От дула тянется лазерный прицел: на ПК — к курсору мыши, на телефоне — в центр экрана; голубой — готово, серый — перезарядка. Выстрелы летят из дула со светящимся шлейфом; попавший покрывается инеем, у него синеватый экран и «холодные» края |
| Ускорение / Спринт | Шлейф за персонажем (синий у раннера, красный у трапера), у самого игрока шире угол обзора, линии скорости и ярче цвета |
| Рывок | Белый шлейф и резкий «рывок» камеры |
| Плавное падение | Разноцветный парашют над головой, мягкие светлые края экрана |
| Двойной прыжок | Кольцо воздуха под ногами на втором прыжке |
| Щит | Золотая подсветка персонажа на время защиты |
| Лобби | Плитка, неоновые полосы, башни-леденцы с огнями, световые столбы над кругами, вывеска TRAP RUNNER, парящие фигуры |
| Смерть / финиш | Красная вспышка и тряска камеры при смерти; конфетти при финише; «+N очков» после раунда |
| Музыка | Спокойная мелодия в лобби, быстрее в раунде; кнопка ♪ слева выключает её |
| Второй шанс | Раннер погиб (ловушка, падение, смерть) — появляется окно «ВТОРОЙ ШАНС!» на 8 с. В Studio есть кнопка «Вернуться бесплатно (тест в Studio)»: раннер возвращается на последний пройденный чекпоинт (или на старт) и бежит дальше. Раз за раунд; убийство трапера в этом случае не засчитывается. Пока окно открыто, раунд не заканчивается |

**Музыка.** Без настроек играет встроенная «музыкальная шкатулка». Чтобы поставить настоящие треки, найди в
Creator Store (Audio → Music) бесплатные треки и впиши их id в `src/shared/Config/Music.luau`
(`LobbyTracks`, `RoundTracks`, формат `"rbxassetid://123"`). Если трек не загрузится, снова заиграет шкатулка.

**Второй шанс за Robux.** Создай developer product «Второй шанс» и впиши id в
`Monetization.SecondChance.productId`. После покупки игрок сразу возвращается в забег; если окно уже
закрылось — покупка сохраняется как жетон и предлагается при следующей смерти (жетоны можно купить и заранее
в магазине). Бесплатная кнопка в Studio выключается в `GameConfig.Debug.StudioFreeSecondChance`;
в опубликованной игре её нет никогда.

## Лобби: стенды, гардероб, рейтинги

| Что | Где и как |
|---|---|
| Стенды способностей | Вдоль левой стены — способности раннера, вдоль правой — трапера. Над каждым стендом крутится модель способности, имя и цена. Подойди и нажми E — откроется карточка: описание, «Купить за N очков» / «за R$», «Надеть в слот» |
| Гардероб | Будка в дальнем левом углу (E) или кнопка «ГАРДЕРОБ» слева. Шлейфы, шапки и ауры за очки; надетое видно всем, в лобби и в раунде |
| Топ-100 | Два табло за точкой появления: по очкам и по победам (раннером + трапером), с аватарками; список прокручивается колесом мыши или пальцем. Твоя строка подсвечена |
| Моя статистика | Табло в дальнем правом углу: очки, раунды, финиши, победы, убийства, лучший забег |

Рейтинги хранятся в OrderedDataStore (`TopPoints_v1`, `TopWins_v1`): очки игроков записываются раз в 3 минуты и при
выходе, табло перечитываются раз в минуту. В Studio без доступа к API на табло видны только игроки текущего сервера.
Стенды, гардероб и табло строятся только в стандартном лобби (если ты подложил своё `Assets.Lobby`, их нет).

## Свои модели вместо плейсхолдеров

Положи модель в `ReplicatedStorage.Assets` (папку создаёт Rojo и не трогает её содержимое):

- `Lobby` — должна содержать части `RunnerCircle` и `TrapperCircle` (радиус берётся из атрибута `Radius`
  или из конфига), по желанию `Board` (табло рисуется на грани Front) и `SpawnLocation`.
- `Segment_<id>` (например, `Segment_JumpPlatforms`) — pivot модели в центре пола на входе, взгляд вперёд
  по трассе; длина и перепад высоты должны совпадать с `Config/Segments.luau`. Стекло и коридор Трапера
  генератор добавит сам.

Если модели нет или в ней не хватает обязательных частей — строится плейсхолдер из примитивов.

## Инструменты

- `stylua src` — форматирование, `selene src` — линтер.
- Для автодополнения и проверки типов в VS Code: расширение luau-lsp и
  `rojo sourcemap default.project.json --output sourcemap.json --watch`.
